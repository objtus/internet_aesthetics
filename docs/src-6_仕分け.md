## 第1章 節構成案（6c）

**章**：第1章「土壌——Tumblrとフォークソノミー」（時間軸 1994〜2011年）  
**方針**：GeoCities → Tumblr の現行の流れに、その間の「音楽期プラットフォーム」を2節挿入。MySpace と mp3ブログは性質が違うため**別節**にする。

```
## GeoCitiesという楽園と、その消滅        （既存・L35）
## mp3ブログ——音楽を配り、選ぶ場          （新設・§1）       ← 配布／キュレーション
## MySpace——カスタマイズされる自己と音楽   （新設・§17）      ← プロフィール／対 Facebook／2019 消失
## Tumblrというアーキテクチャ              （既存・L53、§18 で補強）
## フォークソノミーという論理              （既存・L77）
...
```

**節の役割**

| 節 | 素材 | 主点 | 第2章への接続 |
|---|---|---|---|
| mp3ブログ（新設） | §1 | 定義、Fluxblog／Said the Gramophone／Stereogum、ブログ→レーベル/会場/ジン（Altered Zones 2011）、「labels are pals」 | 20jfg・Tri Angle（第2章 Block A）の前提 |
| MySpace（新設） | §17 | 創設（2003）、Top 8・カスタマイズ、音楽発見、2019 データ消失（GeoCities と並ぶアーカイブ喪失）、対 Facebook 均質化（スレッドC） | GATEKEEPER／Modern Witch の MySpace（第2章 L207・L251）の前提 |
| Tumblr 補強 | §18 | Karp の MySpace 継承・Facebook 批判、匿名性と親密性 | 匿名性は 6f／rev-9 へ |

**配置の意図**：GeoCities（個人ページ・喪失）→ mp3ブログ（音楽の配布・選別）→ MySpace（プロフィール・音楽・喪失の二例目）→ Tumblr（リブログ・フォークソノミーで統合）という、Tumblr へ至る土壌の積み上げ。

**順序**：mp3ブログ節（§1）は素材が揃っているため [`第1章取込_プラットフォーム_文案.md`](../第1章取込_プラットフォーム_文案.md) に**先行ドラフト済み**。MySpace（§17）・Tumblr 補強（§18）は同ファイルで続いて執筆する。
