# lo-fi / HD の二つの流れ：草稿全体の構造メモ

## この区分について

本稿がlo-fiとHDという区分を用いることは、第6章で論じた「遡及的確定」の操作そのものだ。当時の実践者がそのように自己理解していたわけではない。Eccojamsとfar side virtualの対比は、後からみれば鮮明だが、2010年当時は同じシーンの実験の幅として存在していた。この区分は、後の展開——vaporwaveとdistroid/hyperpopへの分化、そしてCARIがNeo-Y2Kを参照した経路——を念頭に置いたときにはじめて有効な分析軸として立ち上がる。

lo-fi/HD区分を行っているのは筆者自身であり、すでに語られている区分を紹介しているわけではない。この点を文章のなかで明示することは、誠実さとメタ的な自覚の表明として意味がある。

---

## 三層の整理

### 第一層：遡及的な位置づけという認識論的注釈

lo-fiとHDの二つの流れは、当時からはっきりした潮流として見えていたわけではない。後から振り返ることで見える区分だ。

DUMMY magazineの二本の記事（2012年7月）がその遡及的な命名の契機に最も近い。Adam Harperがvaporwaveを、Charlie Jonesがdistroidを、それぞれ記述することで、同じシーンの二つの方向性が批評的に可視化された。しかしこれも批評家による命名であって、実践者が自覚的にそう分かれていたわけではない。

さらにいえば、seapunkの発端ツイートが「命名」に見えるのも遡及的な視点だ。Lil Internetのツイートは夢の記録であり、命名の意図はなかった。語が後にラベルとして機能したのは、ハッシュタグ化とムーブメント化を経てからのことだ。遡及的な視点は、seapunkの歴史記述にも同様に働いている。

こうした遡及的確定は歴史記述において普遍的に起きることであり、本稿のlo-fi/HD区分もその一例として自覚的に位置づける。

### 第二層：共通の母体から出た実験の混在

OPNとFerraroは同じシーンにいながら対照的な方向性を持っており、しかも同一人物（Ferraro）がlo-fi側（Eccojams的感性）とHD側（Far Side Virtual→BODYGUARD/distroid）の両方を体現していた。

この事実は、二つの流れが最初から分かれていたのではなく、同じ母体から出て徐々に分化したことを示している。2000年代後半から2010年代前半のエクスペリメンタル音楽シーンは、lo-fiとHDの両方が同じ場所で、ときには同じ作り手のなかで試みられていた。区分の明確化は、実践よりも後から来た。

vaporwave内部でも同様だ。proto-vaporwaveの象徴的なアルバムとして並べられるEccojamsとFar Side Virtualは、共通の出自を持ちながら質感において対照的だった。両者が「vaporwaveの前史」として同じ系譜に収まったのは、共通する部分（消費文化への参照、過去のメディアの再利用）が注目されたからであり、質感の相違は二次的な問題として後景に退いた。

### 第三層：HD側の展開とaesthetic制度化への接続

distroid→PC Music→hyperpop→Neo-Y2Kという展開が、第6章のCARIへつながる。

CARIはvaporwaveコミュニティ（r/Vaporwave）から出発したEvan Collinsが設立した。しかし2016年のGuardian記事でCARIが参照した「現代のY2K aestheticの実践」としてのNeo-Y2Kは、PC Musicの高精細・未来的な感性——すなわちHD側の展開——と系譜を共有していた。

つまり：
- vaporwave（lo-fi側）を出発点とするコミュニティが
- HD側の展開（Neo-Y2K）を通じて
- aesthetic制度化の対象と方法を形成した

vaporwaveとdistroid/hyperpopは、aesthetic制度化の出発点（CARIが参照したvaporwave）と、制度化が参照した対象（Neo-Y2K）の両方に絡んでいる。第2章の二つの流れは、第6章で再び交差する。

## 草稿全体を貫く視点としての位置づけ

lo-fi/HDの二つの流れは、本稿の以下の論点と交差している：

1. **命名と充填の構造**（第2章）：実践が先にあって区分が後からつく。充填されなかった命名（distroid）はHD側に集中している。
2. **aestheticの逆転**（第3章）：aesthetic概念がlo-fi的な質感（vaporwave）を土壌に育ちながら、HD側の展開（PC Music/hyperpop）を内包するに至る。
3. **制度化の主体**（第6章）：lo-fi側のコミュニティが、HD側の展開を参照しながら制度化を進めた。
4. **遡及的確定**（第6章→第2章への参照）：本稿の分析視点そのものが、第6章で論じたaesthetic命名の操作と同型である。
