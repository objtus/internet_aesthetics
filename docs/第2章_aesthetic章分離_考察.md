## 1. 独立章にするか

### 判断：**する**

| 材料 | 所見 |
|---|---|
| **論旨の独立性** | 第2章＝イベント史（命名・レーベル・ムーブメントの生死）。aesthetic 節＝**語彙・文法・分類軸の転換**（包含関係の逆転・二軸テーゼ）。時期は重なるが論点が異なる |
| **第2章の比重** | 草稿 L200–754＝**555行**（全5章中最大）。aesthetic 節 L536–621＝**86行**（第2章の約16%）だが、現状でも第2章中盤に根幹論点が埋もれている |
| **自己完結度** | 冒頭が序文 L29 の包含逆転予告を受け、年表（Cluster Mag→Bebe→Savvy J→KYM→三レジスタ）で完結し、末尾が二軸テーゼ＋「第5章で述べる」伏線で閉じる。**章として独立可能** |
| **今後の拡張** | [`aesthetic_文法分析メモ.md`](../notes/aesthetic_文法分析メモ.md)（三モード・質/種の複数・用例年表・二軸統合）と [`internet_aesthetic語と制度化_調査ノート.md`](../notes/internet_aesthetic語と制度化_調査ノート.md)（複合語・Wikipedia・EBSCO）は、現行86行では収まらない。**reorg なしで rev すると第2章がさらに肥大化** |
| **読者動線** | 根幹論点（本稿のテーゼ）が第2章中盤→第5章制度化まで距離がある。**独立章化で「語彙の転換」を明示的な中間章にできる** |
| **ed-6 との住み分け** | 序文＝最小限のカテゴリ語・制度化予告。**厚みは新第3章（rev-1）＋第6章（rev-2b）へ**。三重記述のリスクを章レベルで分散できる |

### 分離しない場合のリスク

- 第2章が rev-1/2 後 **700行超**になり、seapunk 内紛・DMY 政治化・PC Music と同じ章に語彙論が混在する
- 「命名の時代」という章題と aesthetic 節の論旨が読者にずれて見える
- 分割稿 [`第2章_命名の時代.md`](../manuscript/第2章_命名の時代.md)（現 ~549行）の編集・推敲コストが継続的に高い

### 分離する場合のコスト

- 5章→6章の**章番号付け直し**（reorg-2）
- 相互参照の機械更新（下記「移動ブロック一覧」）
- DMY 節と aesthetic 節の **2012年7月・11月の二重記述**（rev-1 で整理）

**コストは reorg-1/2 で一度払えば済む。rev 前に払う方が、後の書き換えの自由度が高い。**

### Cluster Mag 遡及（L540）——**新章内に残す**

**理由**

1. 節冒頭2段落の役割は「internet aesthetics **以前**の一般用法」を示し、2012年以降の充填との**対比軸**である
2. seapunk 節（L493–534）には Cluster Mag の**音楽・遺産**側（Blank Banshee・MASSAGE 9）が既にある。**批評語彙としての aesthetic** は新章の射程
3. seapunk 節へ還流すると、seapunk 節がさらに厚くなり ed-3（読み道整備）の対象と競合する
4. 分割稿でも aesthetic 節 L334 付近に統合済み——**移動単位を割らない**

**rev-1 での調整**：Cluster Mag 段落を「2011・モード3の芽」として文法分析メモの表1と接続。seapunk 節側は「後述第3章参照」1文までに留める（任意・reorg-1 では触らない）
