# 情報密度の高い文章のための推敲ガイドライン

これは**作成のためのガイドラインではなく、推敲専用のガイドライン**である。既に書かれた文章に対して、フラクタル状に文→段落→節→章の順で手を入れることを想定する。

---

## 0. 大原則（全階層に優先する）

- **原意を変えない**：推敲は表現・構成の調整であり、著者が伝えようとした事実関係・主張・ニュアンスを変更しない。判断に迷う箇所は変更せず残す。
- **不要な変更をしない**：基準に照らして明確に問題がある箇所のみ手を入れる。「変えられるから変える」を避ける。好みによる書き換えは推敲ではない。
- **効果的な修正を優先する**：同じ問題に対して複数の直し方がありうる場合、最小の変更で最大の改善が得られる方を選ぶ。

---

## 1. 文（sentence）レベル

**責任範囲**：一文の中で情報が正しく・読みやすく配列されているか

- [ ] **語順**：節を先に句を後に、長い修飾語を先に短い修飾語を後に並べているか
  - **判定法**：修飾語を書き出して長さ（文字数）順に並べ替え、実際の語順と一致するか確認する
- [ ] **主題の一意性**：その文の主題が一つに定まっているか
  - **判定法**：文中の「は」を数える。2回以上現れる、または「は」で示される対象が2つ以上あれば分割候補
- [ ] **情報量のピーク**：一文に詰め込まれたファクトの数が突出して多くないか
  - **判定法（相対閾値）**：固有名詞・年代・数値の合計個数を数える。前後の文の平均の2倍以上であれば分割候補
  - **判定法（補助）**：固有名詞・年代・数値がなくても、引用句・定義句・並列述語の連結数を数える。1文に3つ以上の独立した引用・定義・並列要素（「Aであり、Bであり、Cでもある」型を含む）が連結されている場合も分割候補とする（事実の羅列型だけでなく、定義の引用や並列述語を積み重ねる型の密度もここで拾う）
  - **判定法（絶対閾値）**：前後の水準にかかわらず、1文につき固有名詞・年代・数値の合計が5要素以上であれば常に候補とする。批評史・引用の多い章など、前後の文も含めて全体が高密度な「高原状」の文章では、相対閾値（前後平均との比較）だけでは密度の差が検出されず見逃されるため、絶対閾値を併用する
  - **非対称性テスト（高原状の章での選定基準）**：絶対閾値超過の候補が大量に出る「高原状」の章では、候補全部を分割してはならない。全部を分割すると高い一様から低い一様に変わるだけで、密度の凹凸（分散）がかえって失われる。各候補について「分割した場合、片方が明確に軽い文（帰属・接続・経過のみで固有名詞・年代を含まない文）になるか」を確認し、**非対称に割れる候補だけ**を実行する。両方とも中密度にしかならない候補は保留する。分割後は章全体の密度プロファイルを見直し、山と谷が交互に現れているか確認してから、必要であれば追加の候補を検討する
- [ ] **主語交代の連鎖**：一文の中で「が」を伴う複数の節が連結され、その都度主語（が）が交代していないか
  - **判定法**：文中で連用形・て形によって連結された節を数え、それぞれの節の主語（が）が同一かどうか確認する。異なる主語への交代が2回以上あれば候補とする
  - **背景**：「は」の出現回数を見る主題の一意性チェックでは拾えない問題。「は」が一度も現れない文でも、「が」主語が節ごとに交代しながら連結されていると、読者は常に「今どの主語の話か」を更新し続ける負荷を負う
- [ ] **修辞と事実の優先順位**：比喩・修辞技法が事実の正確さより前に出ていないか
  - **判定法**：比喩・強調表現を一時的に削って読み、事実関係が変わらず伝わるか確認する。伝わらなければ修辞が事実を代替してしまっている
- [ ] **簡潔性**：形容語・副詞に削れるものが残っていないか
  - **判定法**：各形容語・副詞を一つずつ仮に削除し、文意が変わらなければ削除候補
- [ ] **主題直前の入れ子修飾の深さ**：主題（は）に到達するまでに、読者が保持しなければならない帰属・所属の層が積み重なりすぎていないか
  - **判定法**：「の」「による」など所属・帰属を示す助詞の連鎖を、主題の「は」に到達するまで数える。3層以上、かつそのうち2つ以上が固有名詞ラベル（鍵括弧付き等）を伴う場合は候補とする
  - **背景**：「は」の出現回数だけを見る主題の一意性チェックでは拾えない問題。主題そのものは一つでも、そこに到達するまでの入れ子の深さが処理負荷を生む（中央埋め込みに近い構造）
- [ ] **文末表現の反復**：隣接する文で同一の定型的な文末パターンが連続していないか
  - **判定法**：隣接する2〜3文の文末（「〜のひとつだ」「〜と言える」「〜だろう」等）を比較し、同一の定型表現が連続していないか確認する
  - **対応の目安**：一方を別の言い回しに変える、または文を統合する。ただし意図的な反復（リズムを作る技法）である可能性を候補化の段階で必ず検討する
- [ ] **帰属の遅延**：文の内容が「誰の発言・主張の要約か」の確定（「〜という内容だ」等）が文末まで先送りされていないか
  - **判定法**：文中に独立した主張・命題が2つ以上、読点のみで接続されている（句点による分離がない）状態で、かつその帰属（誰の発言／地の文かの別）が文の最後の節でしか判明しない場合を候補とする
  - **背景**：「主題直前の入れ子修飾の深さ」の逆向きのパターン。あちらは主題到達前に負荷がかかるのに対し、こちらは文の意味の確定（帰属先）が文末まで遅延することで、読者が独立した複数の主張を宙づりのまま処理させられる
  - **対応の目安**：帰属を示す語句（「〜の内容は次の通りだ」等）を文頭に移動し、後続の独立した主張は句点で分離する

## 2. 段落（paragraph）レベル ★最重点

**責任範囲**：一つの主題が立ち、処理容量が管理され、次への推進力があるか

- [ ] **主題展開パターンの判定**：段落がどの型かを見極める
  - **一貫展開**：同一の主題について複数の側面を述べる（既定・最も安定）
  - **線状展開**：前の文の新情報が次の文の主題になり、話題が連鎖していく（時系列・因果関係を追う段落に向く）
  - **分裂展開**：一文の新情報が複数要素を含み、後続の文でそれぞれを掘り下げる（列挙の直後に向く）
  - **判定法**：各文の主題（は・が）を書き出し、「同一」「前文の新情報の引き継ぎ」「複数への分岐」のどれに該当するか分類する。3文以上どれにも該当しなければ「散漫」と判定
- [ ] **一段落一トピック（一貫展開の場合）**：段落の主題を一語〜一句で言えるか
  - **判定法**：実際に一語〜一句で書き出してみる。書けない場合は分割候補。ただし線状展開・分裂展開を意図している段落にはこの基準をそのまま適用しない
- [ ] **トピック文の射程と段落内容の一致**：トピック文（段落冒頭の主題文）が宣言する範囲と、段落内の実際の内容の射程が一致しているか
  - **判定法**：トピック文に時間・数量・範囲を限定する語句（「2022年には」「三つの」等）がある場合、段落内の全ての要素がその範囲に収まっているか確認する。収まらない要素（範囲外の年代・数量など）が一つでもあれば候補とする
  - **背景**：「一段落一トピック」チェックだけでは拾えない問題。トピック文自体は一意で明確でも、宣言する範囲と実際の内容の射程がずれている場合がある
  - **上位階層への一般化**：この基準は段落のトピック文に限らず、章・節冒頭の射程宣言（「時間軸：1994〜2011年ごろ」等のメタデータ表記を含む）にも同様に適用する。章・節末尾までの内容が宣言された範囲（特に時間軸の終端）に収まっているか確認し、超過があれば候補とする
- [ ] **具体性レベルの一貫性**：各文が並列（同レベル）か従属（一段ずつ具体化）かが判別できるか
  - **判定法**：各文に具体性レベルを番号で振る（抽象1→具体2→具体3、など）。番号が2つ以上一気に飛ぶ、または番号が逆行する箇所は要確認
- [ ] **密度の波**：密な情報段落が連続していないか
  - **判定法**：段落ごとに固有名詞・年代・数値の合計を数える。前後平均の1.5倍以上の高水準が3段落以上連続していないか確認
- [ ] **まとめ＋転回判定**：段落が既知情報の反復だけで終わっていないか
  - **判定法**：まとめの段落の後半に新しい問い・転回が一文以上入っているか確認する。入っていなければ削るか転回を足す
- [ ] **橋渡し**：次の段落へ繋ぐ要素があるか
  - **判定法**：段落の最後の一文と次の段落の最初の一文を並べて読み、主題が唐突に切り替わっていないか確認する
- [ ] **確信度の書き分け**：確定事実・推測・未検証の情報が同じ強さの文体で書かれていないか
  - **判定法**：断定の語尾（〜だ・〜である）と推測の語尾（〜と考えられる・〜だろう）が、対応する情報の確からしさと一致しているか確認する

## 3. 基準を下回った時の対応

閾値割れは「修正の候補」であり「修正の指示」ではない。判定と実行の間に必ず判断の段階を置く。

### 3-1. 三段階の手順

1. **候補化**：閾値割れを見つけたら、まず意図的な逸脱（強調のための例外など）でないか検討する
2. **介入の種類を選ぶ**：不可逆性が低い介入から順に検討する
3. **実行**：最小の介入で試し、解決しなければ次の介入に進む

### 3-2. 介入の優先順位（不可逆性が低い順）

| 優先度 | 介入 | 内容 |
|---|---|---|
| 1 | **並べ替え** | 既存の文・段落の順序を変えるだけ。情報の追加・削除がなく最も安全 |
| 2 | **分割** | 一つの文・段落を二つに割る。内容は変えず構造だけ変える |
| 3 | **統合** | 細かすぎる単位を一つにまとめる |
| 4 | **橋渡しの挿入** | 接続詞・一文だけの繋ぎを足す。新しい主張は加えないが、構造的な補助を加える |
| 5 | **削除** | 冗長語・重複情報を削る。情報が減るため最も慎重に行う |

**避けるべき介入**：新しい説明・言い換え・具体例の追加。これは推敲ではなく加筆であり、原意を変えないという大原則から外れる。

### 3-3. 基準別の対応マッピング

**文レベル**

| 基準割れ | 第一候補の対応 |
|---|---|
| 主題の一意性NG | 分割 |
| 情報量のピークNG（相対閾値・単発） | 分割、または前後の文とのバランス調整 |
| 情報量のピークNG（絶対閾値・高原状で大量発生） | 非対称性テストを適用し、非対称に割れる候補のみ分割。対称にしか割れない候補は保留 |
| 修辞と事実の優先順位NG | 削除（比喩を外し平叙文に戻す） |
| 簡潔性NG | 削除 |
| 主題直前の入れ子修飾の深さNG | 分割（外側の帰属情報〈誰が・何の〉を独立した文に切り出し、主題を含む本題文を後に続ける） |
| 文末表現の反復NG | 削除または統合（一方の文末を別表現に変える、または2文を1文に統合する。意図的な反復であれば保留） |
| 帰属の遅延NG | 並べ替え＋分割（帰属を示す語句を文頭に移動し、後続の独立した主張は句点で分離する） |
| 主語交代の連鎖NG | 分割（主語ごとに文を分ける。分割後は橋渡しが必要になる場合が多い） |

**段落レベル**

| 基準割れ | 第一候補の対応 |
|---|---|
| 主題展開パターンの散漫 | 並べ替え（まず文順の変更で改善するか試し、解決しなければ分割） |
| 一段落一トピックNG | 分割（分割後は橋渡しが必要になる場合が多い） |
| トピック文の射程と段落内容の不一致 | 案A：トピック文の限定語句を修正（最小の介入、優先）／案B：射程が異なる要素を段落ごと分割 |
| 具体性レベルの飛び | 橋渡しの挿入（中間の具体度を持つ一文。既存内容の展開に限り、新情報は加えない） |
| 密度の波NG | 並べ替え（高密度段落の一部を後方に移動して分散させる）。解決しなければ疎の段落の挿入 |

### 3-4. 機械的に直せない基準がある

一部の基準は、事実関係が複雑で本質的に一文・一段落に複数の要素が必要な場合がある（因果関係を圧縮して書く箇所など）。この場合は**修正せず保留し、著者の判断に委ねる**。閾値は「注意を向けるべき箇所を機械的に拾い上げる」ためのものであり、「必ず直せ」という指示ではない。

## 4. 節（section）レベル

**責任範囲**：読者がどこにいて何を追っているかを見失わないか

- [ ] **道標の設置**：節の冒頭に「この節で何を扱うか」を示す一文があるか
  - **例外**：節に見出しがある場合、見出し自体が道標（interactive metadiscourse）として機能するため、冒頭の道標文は必須としない
- [ ] **問いの単一性**：節全体が追う問いが一つに定まっているか、途中ですり替わっていないか
- [ ] **まとめの位置**：節末ではなく次節冒頭にまとめ（既知の確定＋新しい導入）を置けるか
- [ ] **段落配列の必然性**：節内の段落を並べ替えると論理が破綻するか（破綻しないなら配列が恣意的である可能性）
- [ ] **（任意・エッセイ的要素との併用時）緊張の設計**：認知ライティングでいう「未回収の緊張」「密度の波」の技法を節構成に取り入れる場合、事実の正確さを損なわない範囲に留めているか

---

## 5. 章（chapter）レベル

**責任範囲**：全体の構造が一貫し、途中から読んでも迷子にならないか

- [ ] **逆アウトライン一致**：各節の要点を一行ずつ抜き出して並べたとき、論理が飛んでいないか
- [ ] **節をまたいだ内容の重複**：離れた節で同じ主張・同じ例が再度なされていないか
  - **判定法**：逆アウトラインで書き出した各節の要点を見比べ、同一の主張・同一の具体例（固有名詞・事例）が2つ以上の節にまたがって登場していないか確認する。段落単位のチェック（隣接する段落の比較）では発見できないため、章全体の逆アウトラインを実際に書き出して初めて拾える
  - **対応の目安**：どちらかを削除するのではなく、後方の言及に「先に触れた〜が示すように」等、前方への参照を明示する一言を足す。両者が異なる文脈上の役割（導入としての初出、別の観点からの再定式化）を担っている場合は、削除より参照の明示を優先する
- [ ] **文体装置の反復（章をまたぐ）**：同一の構文テンプレート（列挙構文・文末表現・レトリック技法等）が、複数の章にまたがって繰り返し使われていないか
  - **判定法**：原稿全体（複数章）を通して、同一パターンの構文が何回出現するか数える。1〜2回の出現は書き手の文体上の特徴として保留し、**3回目以降の出現**を候補として意識に上げる
  - **背景**：単発の出現では意図的な技法として問題にならないが、頻度が増すと「効果的な署名」か「同じ型への依存」かの判断が必要になる。この判定は章単位のチェックでは完結せず、原稿全体を通した記録が必要
  - **除外規定**：引用文（他者の発言・文章の引用）内に現れる構文・技法は、著者自身の文体ではないため台帳にカウントしない
  - **対応の目安**：削除・修正を急がず、まず著者に「同じ構文が◯回目である」という事実を提示し、意図的な反復か癖かの判断を委ねる
- [ ] **主題の通し確認**：章全体で「結局何についての章か」を一文で言えるか
- [ ] **確信度表示の一貫性**：確定・推測・未検証の書き分けが章内で統一されているか
- [ ] **再訪可能性**：読者が途中の節から読み始めても、その節単独で成立するか

## 6. 運用ルール

- 優先順位は**段落 ＞ 文 ＞ 節 ＞ 章**。段落は「主題の単位」と「情報密度の管理単位」が重なる場所であり、段落の健全性が他の3層のチェックのしやすさそのものを左右する（逆アウトラインは段落単位の要約であるため）。
- 各階層のチェックは独立に行い、上位階層の問題を下位階層の修正で誤魔化さない（例：節の道標が欠けている問題を、文レベルの言い換えで解決しようとしない）。
- 認知ライティング由来の要素（緊張・逡巡・密度の波）は、事実密度の高い文章では**節・章レベルの任意項目**として扱い、文・段落レベルの基準（原意保持・情報量管理）と衝突する場合は後者を優先する。
- 数値の閾値（2倍、1.5倍など）は目安であり、実際の原稿の分量感に応じて調整してよい。

### 6-1. 推敲の進め方（粒度を上げていく手順）

1. **上から2段落ずつ、文＋段落レベルをチェックする**。この2層の項目はすべて「隣接する数文・数段落」の比較で完結し、それより広い範囲を必要としない。
2. **節が切り替わったら、その節を通しで節レベルのチェックに戻る**。節レベルの項目は、その節を読み終えた時点で判断できる。
3. **章が変わったら、その章を通しで章レベルのチェックに戻る**。逆アウトライン一致・主題の通し確認・確信度の一貫性・節をまたいだ重複は、その章の中で完結して判断できる。
4. 1〜3を繰り返しながら原稿全体を進める。

この手順により、大半のチェックは「今見ている範囲」だけで完結し、原稿が長くなってもチェックに必要な文脈量は増えない。

### 6-2. 通稿的な項目への対応：台帳方式

項目の大半は局所的（今見ている範囲だけで判定可能）だが、以下の項目だけは原稿全体を通した記録を必要とする、**通稿的な項目**である。

- 節をまたいだ内容の重複
- 文体装置の反復（章をまたぐ）
- 射程宣言の超過（章・節冒頭のメタデータ表記）

これらのために原稿全体（過去の本文すべて）を毎回参照し直す必要はない。代わりに、**圧縮された「台帳」を並行して持ち歩き、都度追記・照合する**方式を取る。台帳は原稿の長さに比例して増えるのではなく、「見つかった特徴的パターンの数」に比例して増えるため、原稿が長大になっても台帳自体は小さく保たれる。

台帳の例：

```
【構文パターン台帳】
- 列挙構文（A、B、C——これら型）：3回
  （初出章・節, 2回目の章・節, 3回目の章・節）

【射程宣言台帳】
- 章・節冒頭の宣言 → 実際の内容の終端（一致／超過）

【主張・具体例台帳】
- 同一の主張・具体例が登場した章・節の一覧
```

運用は**受動的**でよい。過去の章を能動的に再走査するのではなく、今読んでいる箇所で似た構文・主張・射程宣言に出会った時にのみ、台帳と照合し追記する。3-1の候補化の手順（意図的な逸脱でないか検討する）は、通稿的な項目にも同様に適用する。
