```
検索避けそのものが witch house だけの発明ではないが、記号を美学の一部として使う実践は、のちのネット音楽マイクロジャンルに直接引き継がれる。記号は見た目を作るだけでなく、発見の回路にも影響した。キリル文字や △・✝ など記号を含む名前は、当時の検索エンジンでは正確に検索しにくかった。そのアーティストにたどり着くには、ブログのリンクや Tumblr のリブログ、フォーラムの書き込みといった、すでにシーンの内側にいる誰かの手引きが必要だった。読みにくい名前は、作り手を個人から切り離されたペルソナへと変えると同時に、内と外を隔てる敷居としても働いた。
```

## Insertion C（synthesis / `## アーキテクチャ：この時代の問い` 内）

### 現行の締め段落（src-6e 反映済）

```
プラットフォームのエコシステムも、物理メディアへの回帰も、宣伝と作品の融解も、この時代に固有の形をとった。この認識は次の時代へと続く問いを含んでいる。プラットフォームが変われば美学の生まれ方も変わる。
```

### 差し替え：締め段落の前に2段落を挿入し、締めを改稿

```
プラットフォームと物理メディアに加えて、この時代にはもうひとつ、作り手のあり方そのものに関わる特徴があった。自分の名前や顔を後ろに引っ込め、ペルソナや別名義の背後から作品を差し出す身振りだ。ここではこれを匿名性の美学と呼んでおく。名前を中身からずらす手つきは前史で見た Throbbing Gristle にもあったし、正体を伏せた匿名ユニット Drexciya のような先行例も電子音楽には古くからあった。だがインターネットの上では、それは桁違いの自由と速さを得る。witch house はアーティスト名にキリル文字や △・✝ を混ぜ、名前そのものを検索しにくい記号に変えた。vaporwave の Ramona Andra Xavier は Laserdisc Visions、Macintosh Plus、PrismCorp Virtual Enterprises と名義を増やし、ひとりの作り手が架空のいくつもの存在を演出した。OPN の Chuck Person や KGB Man、James Ferraro の BODYGUARD も同じだ。新しい Bandcamp ページひとつが、そのまま新しいアーティストになりえた。

これらは、素顔を隠すための仮面というより、インターネットという場所に固有の存在の仕方だった。ステージに立つ身体ではなく、プロフィール、アバター、検索語、フォローグラフのなかの一点として、作り手はネットの上に現れる。名義は隠れ蓑であると同時に、ネットの上でしか成り立たない人格でもあった。PC Music が QT を架空のエナジードリンクの広告塔に仕立て、所属アーティストを誇張された架空のアイドルとして送り出したのも、その延長にある。美術の言葉を借りれば、特定の場所のために作られ、その場所でしか成立しない作品をサイトスペシフィックと呼ぶ。この時代の音楽と映像は、インターネットをその「場所」として作られ、作り手自身もインターネット固有の存在になった。顔と本名を持つ個人がネットを宣伝に使うのではなく、ネットの上で生まれた人格が作品を差し出す。この反転は、のちの hyperpop が突き詰める架空のポップスターにも、本名を伏せたまま運営される無数の美学アカウントにも引き継がれていく。

プラットフォームのエコシステム、物理メディアへの回帰、宣伝と作品の融解、そして作り手がペルソナの背後へ退くこと。いずれもこの時代に固有の形をとった。この認識は次の時代へと続く問いを含んでいる。プラットフォームが変われば、美学の生まれ方も、作り手のあり方も変わる。
```

**メモ**：

- 第1挿入段落＝匿名性の通史的な筋（先行例→ネットでの増殖）。固有名はすべて既出。
- 第2挿入段落＝「サイトスペシフィシティ」の核。jargon は「美術の言葉を借りれば…」で平易にグロスし、ネット固有の存在＝作り手の反転を述べ、hyperpop と後年の美学アカウントへ前方接続。
- 締め段落＝従来3軸＋「ペルソナへの退避」を加えた4軸に更新。最後の一文も「作り手のあり方も変わる」を追加。

## 代替案（不採用前提・参考）

匿名性を**独立した `##` 節**（例「## 名前を持たない作り手」）として PC Music 節と総括の間に立てる案もある。最大限の強調にはなるが、総括が考察の自然な home であり、節を増やすと分散するため、**総括への統合（Insertion C）を推奨**。
